# 🚀 Lanzador de Enlaces por Teclas

Una aplicación de escritorio que te permite asignar teclas a URLs y abrirlas rápidamente con solo presionar una tecla.

## ✨ Características

- **Atajos de teclado**: Asigna cualquier tecla a una URL
- **Modo Reemplazo**: Reutiliza la misma pestaña del navegador
- **Modo Incógnito**: Abre enlaces en modo privado
- **Perfiles**: Crea diferentes conjuntos de enlaces
- **Estadísticas**: Cuenta cuántas veces usas cada enlace
- **Exportar/Importar**: Guarda y comparte tus configuraciones
- **Notificaciones**: Feedback visual al abrir enlaces
